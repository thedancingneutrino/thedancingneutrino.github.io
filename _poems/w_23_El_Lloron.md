No se debe regar con lágrimas la luna
Mas que una vez al mes. 
Cuando el brillo no alcanza 
A reflejarse en sus lugares sagrados.

No se pinta con acuarela de nostalgia plena
La casa cuyos colores aún estallan. 
Cuya puerta aún canta 
Una melodía conocida al tocarla

Se llora como advertencia
Se llora para despedir
Se llora para lamentar, para compartir
Se llora el duelo de un atardecer 
Porque no amanecerá 

Se llora para que se nuble la mirada.
Para extrañar la luna 
en una lámpara de mi casa.
